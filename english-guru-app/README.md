# English Guru — সম্পূর্ণ গাইড 🇧🇩

বাংলা ভাষাভাষীদের জন্য প্রিমিয়াম ইংরেজি শেখার অ্যাপ — ডিকশনারি, লেভেলভিত্তিক লেসন, AI প্র্যাকটিস (ভয়েসসহ), কিডস সেকশন, শর্টকাট ট্রিক্স এবং অ্যাডমিন প্যানেল।

## 🖥️ দ্রুত দেখা (কম্পিউটারে)

**সবচেয়ে সহজ উপায়:**

1. `index.html` ফাইলে ডাবল-ক্লিক করুন → ব্রাউজারে খুলবে
2. অথবা ফাইলটা Chrome-এ টেনে ছাড়ুন

**মোবাইল-ভিউ দেখতে:** ব্রাউজারে `F12` → মোবাইল আইকন (📱) → iPhone/Android বেছে নিন।

## 📱 ফোনে টেস্ট করা

### উপায় ১: কম্পিউটার + ফোন (একই WiFi)

```bash
# অ্যাপের ফোল্ডারে টার্মিনাল খুলে চালান:
npx serve .
# অথবা
python -m http.server 8000
```

তারপর ফোনের ব্রাউজারে `http://কম্পিউটারের-IP:8000` খুলুন।

### উপায় ২: শুধু ফোনেই (সবচেয়ে সহজ)

Android-এ **Termux** অ্যাপ ইনস্টল করুন:

```bash
pkg install node
cd /sdcard/Download/english-guru-app  # ফোল্ডারটা এখানে রাখুন
npx serve .
```

অথবা **"HTTP Server"** টাইপ ছোট্ট অ্যাপ প্লে স্টোর থেকে নামিয়ে ফোল্ডারটা সার্ভ করুন।

## 🤖 AI সেটআপ (ফ্রি)

AI চ্যাট ও ভয়েস কথোপকথনের জন্য Groq ব্যবহার করুন — সম্পূর্ণ ফ্রি:

1. https://console.groq.com → Google অ্যাকাউন্ট দিয়ে লগইন
2. "API Keys" → "Create API Key" → কপি করুন (`gsk_...` দিয়ে শুরু হবে)
3. অ্যাপের ⚙️ অ্যাডমিন প্যানেলে যান (ডিফল্ট পিন: **1234**)
4. "🤖 AI" ট্যাবে key টা পেস্ট করুন → সেভ করুন

**যা কাজ করবে:**
- ✅ টেক্সট চ্যাট (AI-এর সাথে কথা)
- ✅ ভয়েস ইনপুট (মাইকে বলুন)
- ✅ অটো-ভয়েস মোড (AI বলে, তারপর আপনি বলুন — হাতে বাটন চাপা লাগে না)
- ✅ ব্রাউজারে ভয়েস ইনপুট (ফ্রি, key ছাড়াই)

## 📱 APK বানানো — অটোমেটিক (GitHub Actions)

সবচেয়ে সহজ উপায় — কম্পিউটারে কিছুই ইনস্টল করতে হবে না:

1. এই প্রোজেক্টটা আপনার **GitHub অ্যাকাউন্টে** একটি নতুন রিপোতে রাখুন (বা ZIP আপলোড করুন)
2. GitHub → **Actions** ট্যাবে যান → "Build English Guru APK" চালু করুন
3. ৩-৫ মিনিট অপেক্ষা করুন → **Artifacts** থেকে `english-guru-apk.zip` ডাউনলোড
4. ZIP টা আনজিপ করে ফোনে পাঠান → ইনস্টল

**ম্যানুয়ালি বানাতে চাইলে** (Android Studio লাগবে):
```bash
cd english-guru-app
./gradlew assembleDebug  # অথবা Android Studio → Run
```

APK পাবেন: `android/app/build/outputs/apk/debug/app-debug.apk`
